01

About this list

This page identifies third-party providers that Fit2Trade uses to support delivery of the Fit2Trade service and that may process customer personal data as subprocessors, depending on the service, module, region or configuration in use.

Not every provider is necessarily used for every customer. Contractual obligations concerning subprocessors, including any notification process, are governed by the applicable Customer Agreement and Data Processing Agreement.

02

Cloud & infrastructure

Role / purpose

Core compute, databases (including Azure SQL), blob storage and identity services (including Microsoft Entra ID).

Subprocessor

Microsoft Ireland Operations Ltd / Microsoft Corporation (Microsoft Azure).

Role / purpose

User authentication and credential management.

Subprocessor

Auth0 (Okta).

03

Transactional email & notifications

Role / purpose

Delivering password resets, enrolment confirmations, compliance deadlines and digest reports.

Subprocessors

SendGrid (Twilio) and Postmark.

04

Content delivery & security

Role / purpose

Global edge caching, DDoS protection, Web Application Firewall (WAF) services and DNS or traffic routing.

Subprocessors

Cloudflare, Microsoft Azure Front Door and Fastly.

05

eLearning standards & media

Role / purpose

SCORM/xAPI course hosting, video or learning-content delivery, transcoding and adaptive streaming where applicable.

Subprocessor

Rustici Software (SCORM Cloud).

06

Error monitoring & telemetry

Role / purpose

Capturing server logs, crash reports and performance metrics for service operation, security and troubleshooting.

Subprocessor

Microsoft Azure Application Insights.

07

User support & in-app help

Role / purpose

Live-chat or support widgets, onboarding assistance and customer-service tickets where enabled.

Subprocessor

Freshdesk.

Questions and updates
